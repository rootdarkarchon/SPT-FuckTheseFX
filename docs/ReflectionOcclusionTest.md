# Reflection occlusion test

Install 1.6.5 with its matching assets and restart once. Enable Advanced settings, then use **XeGTAO / Reflection occlusion fix** to compare on/off live in the same scene. It defaults on and requires Custom Ambient Fix enabled with strength above zero. Keep AO radius, ambient strength, foliage extra AO and SSR settings unchanged for this comparison. No capture is required.

First check the wall behind the barrels: diffuse contact AO should now remain with the reflection fix both off and on. Version 1.6.5 protects CustomAmbient's diffuse AO from later decal alpha writes in both states. The toggle can still change reflected light, so total scene colour need not be identical. Then check the wet ground and foreground grass as below.

Look at the wet ground near the tyres and pallet, including shallow viewing angles: on should reduce dull reflection patches on smooth surfaces that consume the deferred reflection-occlusion channel. Fully rough surfaces and diffuse contact shading should retain their previous AO. Check while moving the camera so SSR hits can transition to probe fallback. The feature also uses each optic camera's own inputs. Water coverage depends on its rendering path and has not been established by the shader fixtures.

The correction uses `reflectionVisibility = lerp(screenAOVisibility, 1, 0.5 * smoothness * smoothness)`. It retains half the screen-space occlusion on perfectly smooth surfaces, with progressively less relief toward fully rough surfaces. For example, visibility 0.4 becomes 0.7 at smoothness 1. This is a controlled visual approximation, not directional specular occlusion. It replaces the previous angle-dependent approximation, which could be a no-op at grazing angles. Invalid G-buffer normals retain the original visibility.

The native reduced-reflection path used by instanced vegetation is excluded. It uses CustomAmbient's exact sampled raw-depth condition, `_CameraMotionVectorsDepth >= _CameraDepthTexture - 0.00001`; this is a rendering-path classification, not a universal foliage identifier. Its G-buffer reflection visibility remains identical with the fix on/off, avoiding an increase in native SSR's probe subtraction on those pixels. Verify that the foreground grass retains its shading while the wet-ground improvement remains. Foliage AO controls and diffuse AO are unchanged.

The shared G-buffer material-occlusion channel carries authored material AO multiplied by the reflection-specific screen visibility. Native probes, CustomAmbient reflections, and native SSR composition all see that channel, including both FTFX SSR reconstruction modes. No independent reflection term is added. A camera-owned R8 target preserves diffuse material/screen visibility before later decals can overwrite the shared alpha channel. CustomAmbient uses this target with the reflection fix both off and on; HDR/LDR emission keeps the original diffuse AO. The target is released when CustomAmbient is disabled, has zero strength or is unavailable. Active CustomAmbient adds one full-resolution single-channel pass, without CPU readback.

The extra foliage pass and its material mask are unchanged. The GPU regression runs actual camera AO, a later alpha-blended decal and CustomAmbient in 18 combinations of HDR/LDR, decal opacity and reflection toggles. It verifies stable diffuse shading and a measurable AO contribution. This establishes the overwrite mechanism and its protection, not which decal draws affect a particular live wall. It does not fix unrelated SSR tracing/history artefacts or change AO radius. Live-game visual quality and performance remain to be checked.
